## 2025-05-15 - Consistent Design System Button Components

**Learning:** Raw `<button>` elements in Next.js/React applications often miss out on standard design system benefits such as consistent focus-visible rings (`focus-visible:ring-2`), active states, hover transitions, disabled styling, and accessible defaults. Using standard design system `<Button>` wrappers across all pages ensures consistent UI and keyboard accessibility.
**Action:** When working with forms or actions, always inspect raw `<button>` elements and update them to use the centralized UI `Button` component.
